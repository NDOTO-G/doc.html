# documents/ — the wiki of witnessed documents

GitHub shows this directory as filenames and renders `.doc.html` files as source. The
directory is actually a small wiki, and its front door is the shelf:

**Start at [`wiki.doc.html`](wiki.doc.html)** — rendered at
[ndoto-g.github.io/doc.html/documents/wiki.doc.html](https://ndoto-g.github.io/doc.html/documents/wiki.doc.html),
or download/clone and double-click it. The shelf links every page, says why each exists,
and pins each with a cross-file witness you can recompute.

A reading order, if you want one:

1. [`wiki.doc.html`](wiki.doc.html) — the shelf: every page, pinned and explained.
2. [`the-wiki-shape.doc.html`](the-wiki-shape.doc.html) — what a collection of witnessed
   documents is, and the rules the shelf follows.
3. [`evidence.doc.html`](evidence.doc.html) — what was measured, what held, what did not.
4. [`essays/`](essays/) — the design essays, each a self-contained argument.
5. [`doc.html`](doc.html) — the founding research corpus, pinned as the ninth leaf.
   Historical where it disagrees with [`../SPEC.md`](../SPEC.md), which is normative.

[`MISSION.md`](MISSION.md) and [`VOWS.md`](VOWS.md) live here too — the why, and the
makers' covenant.
