About this document

This is a writing-room-tail doc.html: every turn carries a live, strictly-increasing UTC-timestamp witness (writing-room epoch, §6.7). No turn has been consecrated yet.

A conforming reader detects tail shape, walks articles in document order, validates each writing-room witness by grammar (and, under the Append profile, strict increase), and reports ORDINAL-ONLY — never a bare PASS — because zero bytes have been recomputed (§6.3, §7.3).

Start the writing room: what happens before a turn is consecrated?

Turn 2 — Assistant

kind: synthesis

A live turn carries a UTC timestamp witness (writing-room epoch, §6.7) — it records this turn's place in sequence but is not hash-recomputed. Consecration later replaces the timestamp with a SHA-256 over these exact bytes.

Turn 3 — User

kind: transcription

So a reader that only ever sees writing-room witnesses can never say PASS?

Turn 4 — Assistant

kind: synthesis

Correct. A tail with zero consecrated witnesses reports the distinct ORDINAL-ONLY verdict, not PASS — the ordinal register (sequence) was checked, but no byte was ever recomputed.
